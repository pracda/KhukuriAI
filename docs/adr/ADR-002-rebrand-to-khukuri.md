# ADR-002: Rebrand from "SentinelAI" to Khukuri

**Status:** Accepted · **Date:** 2026-07-27

## Context

The working name was "SentinelAI" with a log-analysis module called "Sentinel One." SentinelOne is an existing multi-billion-dollar cybersecurity company (EDR/XDR) — a direct name collision in the same industry. Candidates were vetted for collisions: *Prahari* (Nepali for sentinel — clean), *Rakshak* (taken by multiple security AI projects), *Nigrani* (taken by a telematics company), *Khukuri* (clean in software; some security-guard firms in Nepal/India use the name).

## Decision

The platform is **Khukuri**, after the Nepali/Gurkha blade. Org: `khukuri-ai`. Positioning leans on *precision instrument, trusted under pressure* — not weapon imagery. Module names stay plain English (Gateway, Ingest, Incident, Scan Hub, Agent Runtime).

## Consequences

- No trademark collision with an incumbent in our own market.
- Distinctive, memorable name with an authentic founder story.
- All prior "sentinel*" naming in code and folders is archived, not migrated.
